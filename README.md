# Xeneon-Widgets

Custom iCUE widgets for the Corsair XENEON EDGE.

| Widget | Description |
| --- | --- |
| [f1-tracker](f1-tracker/) | Countdown to the next F1 race and driver and constructor championship standings |

## Build and install

Requires iCUE 5.47 or newer and the iCUE Widget CLI:

```
npm install -g icuewidget-cli
icuewidget validate f1-tracker
icuewidget package f1-tracker
```

Double-click the resulting `.icuewidget` file, or use the "+" button in the iCUE Widgets panel, to import it.
